# Booking Platform API

A production-ready Booking Platform REST API built using NestJS, Prisma, and PostgreSQL.

> Backend Engineering Internship Technical Assessment

## Tech Stack

- NestJS
- TypeScript
- PostgreSQL
- Prisma ORM
- JWT Authentication
- Swagger
- Docker

## Project Status

✅ Ready for Review

## Postman Collection

A ready-to-use Postman collection is included in the `postman/` directory.

Features:
- Automatic JWT token management
- Pre-configured environment variables
- Demo workflow covering the complete API
- Pagination and filtering examples
